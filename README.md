# 菊池球数字教学模型

将 FCC / BCC 展开图贴到 26 面多面体上，用于旋转观察菊池图案及极的位置。使用原生 HTML、CSS、JavaScript 和 Canvas；无需安装应用或运行后台服务。

**[打开手机轻量版](https://abigalelu.github.io/kikuchi-sphere-teaching/index-lite.html)** · [原完整对照版](https://abigalelu.github.io/kikuchi-sphere-teaching/index-drawings.html)

## 观察方式

- 鼠标或单指拖动旋转；滚轮、双指或缩放按钮放大缩小。
- 切换 FCC / BCC，选择新增图纸或原版 PDF 对照，保持当前角度与缩放。
- 使用 `[001]`、`[110]`、`[111]` 预设方向；点击球体表面查看单面图案。
- 支持自动旋转、复位，以及方向键、加减键和 Home 键。

## 图纸与模型

`FCCpage1.jpg` 和 `FCCpage2.jpg` 两页构成一套 FCC 模型，`bcc_all2.jpg` 构成一套 BCC 模型。保留原图的线条、色彩、极标签和署名。

模型为 18 个正方形面和 8 个三角形面组成的多面体。它使用固定图案展示，不计算新的衍射关系，也不是用于实体打印的模型。

新图纸 BCC 原图每面约 330 像素，放大后的细节受源图分辨率限制。

## 手机轻量版

默认先下载当前模型的一张 256 像素/面的整体图集，再加载当前查看面的高清图。四种组合仍可切换，切换时保留角度和缩放。拖动结束后，正对观察者的面自动补充高清；点击其它面也会将它设为高清观察面。旋转过程中其它面使用整体图集，细小文字可能较软，点选后可查看原有细节。

高清图保持原贴图分辨率，以无损 WebP 编码；重建脚本对全部 104 张图解码后的可见 RGBA 像素逐一核对。整体图先缩小再压缩；新增 JPG 图纸的整体图采用 WebP 质量 96，原 PDF 整体图采用无损 WebP。原始图纸、原完整对照版和第一版均保留。

| 指标 | 原完整对照版 | 轻量版默认 FCC 首次打开 |
| --- | --- | --- |
| 初次图片请求 | 104 张面贴图 | 1 张整体图 + 1 张高清面图 |
| 初次图片文件量 | 约 63.4 MB | 1,735,574 bytes，约 1.74 MB |
| 稳定状态持有的解码贴图像素量 | 约 224 MB | 9,515,604 bytes，约 9.52 MB |
| 初次加载其它组合 | 全部加载 | 切换时才加载 |

以上使用十进制 MB，图片文件量不含 HTML/CSS/JS 和 HTTP 开销。轻量版解码贴图像素量由 1040×1820 的整体图和当前一个高清面计算；切到正方形高清面时约 9.82 MB。**这些是受代码控制的图片像素量，不是浏览器进程的实测内存。** 还存在画布、临时解码、编码缓存和浏览器自身开销。模拟 390×480 CSS 像素的观察区域，主画布为 1,684,800 像素字节，单面预览画布为 1,048,576 像素字节。

每个图片槽只持有当前图；切换时取消旧请求并关闭已替换的 ImageBitmap。后台停止绘制并释放高清面，离开页面释放两个图片槽。支持 WebP 不可用时的 JPEG/原 PNG 回退，以及 ImageBitmap 不可用时的普通图片解码。普通图片解码回退时，浏览器自身的缓存与回收时机不受页面直接控制。

整体图失败提供重试；单面高清图失败保留球体与低分辨率预览，用户可单独重试。旧版“assets 不完整”是通用加载失败提示，不能据此认定文件永久缺失。

## GitHub Pages

发布源为 `main` 分支根目录，`.nojekyll` 表示直接发布静态文件。无需构建命令，也无需配置自定义域名。

原完整对照版仍会在启动时加载四套贴图，共 104 张、约 63.4 MB。源 JPG/PDF 只在主动打开时请求；轻量版新增资源也只按当前组合和观察面请求，仓库总文件量不等于单次访问的流量。

已检查全部贴图文件、相对路径、四种组合的 Canvas 绘图、方向预设及切换时保留视角。轻量版新增 8 项验证，覆盖初次请求与贴图生命周期上限、快速切换取消、加载失败重试、格式/解码回退、后台恢复和拖动/双指缩放。验证使用模拟事件、模拟网络及原生 Canvas，并非真实 iPhone Safari 的内存、帧率或网络测试。原完整版后来已由维护者确认能在 iPhone Safari 加载，先前失败的具体原因尚未确定。

可选重建工具使用 Node.js 与 `sharp`：运行 `node scripts/build-lite.cjs`。可选检查工具使用 `@napi-rs/canvas`：运行 `node --test scripts/verify-lite.cjs`。这些依赖仅用于制作/验证，浏览器观看无需安装。验证输出在忽略目录 `validation/lite/`。
